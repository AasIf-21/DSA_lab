# 📚 Data Structures & Algorithms Lab

A collection of **Data Structures and Algorithms (DSA) lab programs** implemented for learning and practicing fundamental concepts in computer science.

This repository contains implementations of important data structures, algorithms, searching and sorting techniques, memory allocation methods, and other DSA-related programs.

---

## 📌 Contents

The repository is organized into different sections based on the concepts covered in the DSA laboratory.

| Folder              | Description                                       |
| ------------------- | ------------------------------------------------- |
| `Fibonaccii`        | Fibonacci-related programs and algorithms         |
| `Memory_allocation` | Memory allocation techniques and related programs |
| `Searching`         | Searching algorithms                              |
| `Sorting`           | Different sorting algorithms                      |
| `Stack_n_Queue`     | Stack and Queue implementations                   |
| `heap`              | Heap data structure and related operations        |
| `Others`            | Miscellaneous DSA programs                        |
| `output`            | Sample outputs and program results                |
| `.vscode`           | Visual Studio Code configuration                  |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AasIf-21/DSA_lab.git
```

### 2. Navigate to the project

```bash
cd DSA_lab
```

### 3. Explore the programs

Choose a topic folder and open the required source file.

For example:

```text
DSA_lab/
├── Fibonaccii/
├── Memory_allocation/
├── Others/
├── Searching/
├── Sorting/
├── Stack_n_Queue/
├── heap/
└── output/
```

---

## 💻 Running the Programs

The programs can be opened and executed using a suitable compiler or IDE depending on the programming language used.

For C/C++ programs, you can use:

* GCC / G++
* Visual Studio Code
* Code::Blocks
* Dev-C++
* Any compatible C/C++ IDE

Example using GCC:

```bash
gcc program.c -o program
./program
```

For C++:

```bash
g++ program.cpp -o program
./program
```
